# Myntra-clone
🛍️ Myntra-Inspired Fashion E-Commerce Website
A fully responsive and interactive front-end e-commerce website UI inspired by Myntra, built with HTML, CSS, and JavaScript.

🎯 This project is a UI/UX clone and does not include backend functionalities like user login or payment processing.

🔥 Features
✅ Responsive layout for desktop, tablet, and mobile

🍔 Hamburger menu (mobile-friendly navigation)

🔍 Search input with simulated search alert

👤 Interactive icons: Profile, Wishlist, Bag (clickable with alerts)

📸 Hover animations for product cards

🧼 Clean and minimalist UI

📦 Organized footer with important links
